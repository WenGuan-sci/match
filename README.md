# Crackle Squish

An ASMR squishy toy for the browser. Press, hold and drag the squishy to crack its sugar shell. Every crunch, squelch and bubble sound is made live with the Web Audio API, so there are no audio files.

- 4 squishies (Peach, Cloud, Honey, Mint Ice), each with its own crunch sound
- Stereo panning follows your finger, and phones vibrate on each crack
- Re-coat the shell any time, or turn on Auto ASMR to let it crunch on its own

Open `index.html` in any browser. Headphones recommended.
