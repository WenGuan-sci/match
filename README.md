# Crackle Squish

An ASMR squishy toy for the browser. Press, hold and drag a squishy to crack its sugar shell. Every crunch, squelch, pop, squeak, chime and raindrop is made live with the Web Audio API, so there are no audio files.

Open `index.html` in any browser. Headphones recommended.

## Squishies
Peach, Cloud, Honey (cube), Mint Ice, Strawberry (with seeds), Lemon Star (star shape, sprinkles), Grape Gummy, Galaxy (twinkling stars) and Matcha Mochi (dusted bun). Each one has its own colours, shape and crunch sound.

## Features
- **Tools:** Squeeze, Poke (small crisp cracks) and Smash (big fractures, deep knock, screen shake)
- **Realistic cracks:** spiderweb fractures, light-catching shards, chipped spots and cracks you can drag
- **Combos** for quick crunches in a row
- **Sound styles:** Crack, Slime, Bubble wrap, Squeaky foam, Crinkle, Popping candy, Tapping, Glass chime, or Mix for a random one each press
- **Ambience:** rain, ocean waves or a crackling fireplace in the background
- **Mixer:** volume, effects, squish and ambience levels, plus a vibration toggle
- **All-time stats** for crunches, shattered shells and best combo, saved in your browser
- **Shuffle** for a random squishy, **Re-coat** for a fresh shell, and **Auto ASMR** to let it crunch on its own
- **Keyboard:** Space crunches, 1–3 switch tools, R re-coats, S shuffles

# CE Graphing Calculator

`calculator.html` is a color graphing calculator that runs in the browser and works like a CE-style handheld. Open it in any browser and click the keys or type on your keyboard.

- **Home screen:** MathPrint (stacked fractions, exponents, radicals, Σ, ∫, d/dx templates, fraction answers) or Classic; TI order of operations, `Ans`, `2nd ENTRY`, `STO→`, `RCL`, `►Frac`, `►Dec`, `►DMS`, error screens with Quit/Goto
- **MODE:** MathPrint/Classic, Normal/Sci/Eng, Float/Fix, Radian/Degree, FUNC/PAR/POL/SEQ, line style, Real/a+bi/re^θi, Full/Horizontal/Graph-Table, fraction type, answers
- **Graphing:** Y= editor for all four modes with per-function color and line style, WINDOW, FORMAT, every ZOOM option, TRACE on the CE pixel grid, CALC, TABLE with Ask modes
- **DRAW:** Line, Horizontal, Vertical, Tangent, DrawF, Shade, DrawInv, Circle, Text, Pen, points and pixels, color arguments, StorePic/RecallPic, StoreGDB/RecallGDB
- **Lists and STAT:** list editor, list math, 1/2-Var Stats, every regression, Med-Med, all 17 STAT TESTS with Calculate and Draw, ANOVA, six stat plot types, ZoomStat
- **DISTR:** normal, t, χ², F, binomial, Poisson, geometric, invBinom, plus the DRAW tab (ShadeNorm, Shade_t, Shadeχ², ShadeF)
- **Matrices**, **complex numbers**, **strings** (Str0–Str9), **piecewise(**, **solve(**, numeric **Solver**
- **PRGM:** program editor and TI-BASIC interpreter with control flow, I/O, getKey, subprograms, mode/zoom/format commands, clock and timer functions
- **APPS:** CabriJr (geometry sketchpad), CelSheet (spreadsheet with formulas and ranges), Conics, Finance (TVM, amortization, npv, irr), Inequalz (inequality graphing with intersection shading), Periodic (118 elements), PlySmlt2 (polynomial roots and simultaneous equations), Prob Sim (coins, dice, marbles, spinner, cards, random numbers), SciTools (sig-fig calculator, unit converter, constants, vector calculator), Transfrm (live A/B/C/D coefficients). EasyData and Hub open but report that no sensor or hub is connected.
- **MEM:** Mem Management/Delete, ClrAllLists, Reset; **CATALOG** with every command
- Everything you enter is saved in your browser

Not included: cable linking, exam mode, custom-named lists, Catalog Help, `Select(` and `Manual-Fit`. The apps are working browser versions with the core tools of each, not every menu of the originals; EasyData and Hub need hardware that a web page does not have.
